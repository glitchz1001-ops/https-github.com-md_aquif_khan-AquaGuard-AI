# 💧 AquaGuard AI – Smart Water Leakage Detection System

### AI-Powered IoT Water Monitoring for Smart Campuses

AquaGuard AI is an intelligent water leakage detection and monitoring system designed to identify water leaks, monitor water consumption, and reduce water wastage using IoT sensors and AI-based analytics.

## 🚀 Key Features

- Real-time water flow monitoring
- Water pressure monitoring
- Water leakage detection
- AI-based anomaly detection
- Predictive leakage analysis
- Interactive monitoring dashboard
- Sensor status monitoring
- Alerts and notifications
- Campus water monitoring visualization

## 🏗️ Technology Stack

| Component | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, FastAPI |
| IoT Hardware | ESP32 |
| Sensors | Flow, Pressure, Leak |
| Communication | MQTT |
| Database | Firebase |
| AI | Rules + Machine Learning + Predictive Analytics |

## ⚙️ System Architecture

1. ESP32 collects water flow, pressure, and leakage sensor data.
2. Sensor data is transmitted through MQTT.
3. Python backend processes incoming data.
4. AI logic identifies abnormal water usage and possible leakage.
5. Firebase stores monitoring data.
6. Dashboard displays water usage, sensor status, and alerts.
